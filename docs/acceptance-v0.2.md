# v0.2 验收约定（2026-10-20 冻结）

本轮交付是可显式启用的通用规划管线，不替换原有默认压缩路径。独立于报告 Skill，输入业务定义、保护条件和预算，输出有版本的上下文。验收分为确定性发布门槛与模型观察，不用旧版本实验结果证明新版本。

发布门槛在运行新评测前固定：

- 全部已有测试、新增计划与文本边界测试通过。固定随机种子的 60 组数值及结构检查精确一致。
- 两份公开脱敏生产数据的所有未授权删除单元格、对象顺序、missing/null、来源元数据和统计分母精确一致；保护对象原文全部保留。只允许删除调用方明确授权的文本字段。
- 无效计划、非法算子、等级/ID 当度量、口径变更、漏表、错误引用、预算耗尽、未知对象均不得静默损失数据。
- 受控文本用例的冻结关键原句必须保留，原文定位全部吻合，新增事实为零；否定、条件与冲突用例保留。此处是工程用例，不能称为独立人工专家金标。
- 最终序列化输出按调用方计数器检查；超预算不能删除保护内容，必须返回失败状态。调用次数、输入预算及重试上限均包含失败尝试。
- 真实模型试运行使用同一回答模型、问题及计数器，对比原文、等预算截断、旧规则与新规划路径，保留逐阶段 usage 和失败结果。试运行只验证当前冻结任务可用性，不设立通用语义准确率结论。

自然语言的完整事实召回、跨业务泛化和固定报告 Skill 的报告质量，需要后续独立人工标注与授权业务数据。本轮不以自评或逐字引用证明这三个目标，也不据此替换默认路径。新路径的文本压缩始终需要显式授权；没有授权时保留原文。
