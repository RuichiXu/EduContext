# 简历条目

**教学 Agent 大规模上下文优化：**调研并参考 TAP4LLM、LLMLingua 与紧凑结构化表示，实现零运行时第三方依赖的 Python 任务感知压缩模块，结合实体明细保护、精确聚合、异常证据选择和可追溯结构编码；在超过 42 万字符的合成教学数据上，报告及指定学生任务经两种 BPE 编码复核实现约 28–30 倍压缩，3 项模型对照任务的 21 个关键事实与完整输入同为全部正确，并通过 44 项测试及其中的 360 组随机完整性验证。

面试展开：

- 不把它当自然语言摘要：先计算完整总体的 sum/count/精确均值，再选择解释证据，避免抽样改变统计分母。
- 名称与 ID 关联后保护指定对象全部明细，异常、重要标记、极值见证也受保护；保留行号和输入哈希以便核对。
- 公共字段提取、共享列头和有类型的字符串字典消除结构重复；缺失值和 null 分开表达。
- token 预算含输出协议本身，支持外部精确计数；必要内容超预算时明确失败，候选膨胀时返回完整原文。
- 评测将程序正确性、输入规模和最终模型答题分开衡量，并保留未达到十倍压缩的案例。

使用范围：这是工程原型和合成数据评测，不是生产部署。不要改写成 349 条真实查询、真实教学用户量或 85%→94% 的上线提升；本次完整输入与压缩输入均为 21/21，证据支持的是质量持平和输入缩小。
